            Unlock with passkey

            Skip retyping your master password on this device using Touch ID, Windows Hello, or a security key. The passkey and the key it protects live only in this browser — nothing is sent to or stored on the server, it isn't synced to your other devices, and it doesn't replace your master password (still needed on a new device, or if this browser's data is cleared).

              Reused passwords

              Logins that share the exact same password — if one leaks, all of them are exposed.

                Breach check

                Checks each password against Have I Been Pwned's Pwned Passwords database using k-anonymity: only a 5-character prefix of a SHA-1 hash ever leaves your browser — never the password, never the full hash. This is the only feature in Passvault that makes an external network request, and it only runs when you click the button below.

                  New Send

                  Share text or a file with anyone via a one-time link — they don't need a Passvault account. The decryption key travels only in the link itself (after the #), never through the server, so even this server's operator can't read the content.

                        Export vault

                        Downloads a file containing every item in your vault, DECRYPTED. There's no way around this — that's what makes it usable elsewhere. Store the file securely and delete it once you're done, and never send it anywhere untrusted.

                        Import

                        Bring items in from Passvault, Bitwarden, or Chrome/Google Password Manager. Files are parsed and encrypted entirely in your browser — the plaintext file never touches the server.
